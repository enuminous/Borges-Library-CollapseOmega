## Filing policy

- Preserve published text as archived, including embarrassing jokes, negative results and scientific disclaimers.
- Keep source URL, original Git blob SHA, date, author, genre and the publication-versus-physical-evidence distinction separate.
- Do not overwrite an original with a tidy retrospective interpretation; append an explicitly versioned new record if necessary.
- The mathematics shelf catalogs **Clifford algebra**; the Philosophy cross-file collects the **goddamn** commentary. They are deliberately separate classifications.
