The librarian's promise

All public default-branch files are inventoried unless they belong to transient vendor/cache directories or this catalogue's own generated output. The original source repositories are never edited by Sophia. Each scan records exact Git blob identities and tree SHA references. Errors and old snapshots are clearly labeled.

New to the Library? Visit Sophia's first preserved accession: Those Goddamn Cliffords, Mathematics, Third Gallery; exasperation cross-filed under Philosophy, beside Schopenhauer.

Sophia the Librarian is a fictional editorial persona; the public GitHub record and automated daily refresh workflow are real. File metadata is not an experiment, a mathematical proof, or evidence of global cosmic rotation.
